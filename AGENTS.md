# Learning-first workflow

Build a DNS server in Python to understand UDP, binary packets, DNS records,
name resolution, and forwarding.

Explain the current exercise and trace its bytes and state before implementation.
Review Teja's design and implement only stages explicitly requested. Preserve
learner comments and unrelated work. Passing tests proves behavior, not mastery.

After completing each requested exercise, run focused local checks, make a
separate descriptive commit, submit using `codecrafters submit`, and push the
resulting commits to the public `github` remote. Verify the remote head and
report submission and publication results. Keep `origin` for CodeCrafters.
Do not implement future exercises without authorization or rewrite history.
Never commit credentials or local authentication state.

The initial setup leaves the first exercise unimplemented. Use `uv sync --locked`
to install dependencies and `./your_program.sh` to run locally. On this Mac,
prefix Git and CodeCrafters commands with
`DEVELOPER_DIR=/Library/Developer/CommandLineTools` if the Xcode license blocks Git.
